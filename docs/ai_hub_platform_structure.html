AI_Hub · personal project · platform structure

How the gateway works — from trending repo to a running starter

One scheduled pipeline, one state file, one static site. No servers. V1 · Po
Every six hours the pipeline pulls AI repos, scores trust, labels skill level, tests that they run, and publishes a static site only if six gates pass. Stars never decide the ranking; a dated test and a trust score do.
Project AI_Hub CRS none (no spatial data) Units metric Version V1 Date 07 November 2026 Author PNC Audience Po (owner)
MCP

Model Context Protocol — the plug-in standard that lets coding agents call external tools; MCP servers are one of the three listing types.

Scorecard

OpenSSF Scorecard — a free, weekly security health score for public repositories; one input to the trust score.

Gate

Test gate — an automatic check in the pipeline; the site is deployed only when all six pass.

Cron

Schedule — GitHub Actions runs the pipeline at minute 17 of every sixth hour, nightly at 02:00 and on Mondays at 07:00.

SQLite

State store — one database file, gateway.sqlite, that keeps every snapshot and score; kept as a GitHub release asset, never in git.

Astro

Static site builder — turns listings.json into plain HTML pages served by Cloudflare Pages.

The linchpin

Nothing is ranked by stars and nothing is called "tested" without a dated sandbox run. Every other site stops at popularity; this one shows a reason to trust and the first command to run.
